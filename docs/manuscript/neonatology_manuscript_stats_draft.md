**Statistical Analysis**

Each question was answered by multiple large language models (LLMs), creating clustered observations at the item level. To account for this non-independence, we performed the primary inferential analysis using generalized estimating equations (GEE) with a binomial distribution, logit link, and exchangeable working correlation structure, with question number specified as the clustering variable. The dependent variable was model failure, defined as an incorrect response relative to the reference answer key.

Question-level taxonomy annotation was performed on the examination items and reference answer key before model-performance analysis, without using model-specific correctness outcomes to assign taxonomy labels. We initially explored a broad taxonomy framework including knowledge dimension, cognitive process, reasoning complexity, clinical risk, difficulty, and universal task category. Reasoning complexity was operationalized a priori as `Low` when an item could be answered by direct factual retrieval or a single-step mapping from stem to answer, `Moderate` when it required one inferential step or limited integration of multiple clues, and `High` when it required multistep synthesis across diagnosis, physiology, risk stratification, or management options. Because taxonomy domains were conceptually overlapping and some expanded models produced unstable category-specific estimates, we assessed model specification in a stepwise manner using collinearity diagnostics and quasi-likelihood model fit. Collinearity was examined using Cramer's V for categorical associations and variance inflation factor (VIF) diagnostics. Knowledge dimension and cognitive process showed substantial overlap, and broader models including multiple highly related taxonomy domains yielded unstable or extreme estimates, consistent with sparse-data effects and residual collinearity.

Accordingly, primary inference was based on a reduced clustered GEE model selected for interpretability and stability. The prespecified primary model included cognitive process, reasoning complexity, and universal task category. Reference categories were `Remember` for cognitive process, `Low` for reasoning complexity, and `Physiology and Pathophysiology` for universal task category. Adjusted odds ratios (aORs) with 95% confidence intervals (CIs) were reported. Joint Wald chi-square tests were used to assess the overall contribution of each taxonomy domain. Model fit was summarized using the quasi-likelihood under the independence model criterion (QIC) and the corrected QIC (QICu), with lower values indicating better fit.

Because universal task category showed minimal explanatory contribution in the primary model, we additionally examined a simplified clustered GEE model including only cognitive process and reasoning complexity. This model was treated as a supportive secondary analysis rather than the main inferential model. Sensitivity analyses repeated the primary GEE specification under independence and unstructured working-correlation assumptions. To facilitate interpretation on the absolute scale, we also fit a linear probability model (LPM) with cluster-robust standard errors at the question level as a sensitivity analysis. Finally, we explored a full taxonomy GEE model including knowledge dimension, cognitive process, reasoning complexity, clinical risk, difficulty, and universal task category; given unstable coefficients and poor fit, this expanded model was considered exploratory only. Because category-specific cognitive-process contrasts were secondary subgroup analyses, we additionally applied Holm correction across the four non-reference cognitive-process coefficients within each reduced model.

**Results**

Across all model specifications, reasoning complexity was the most consistent predictor of LLM failure. In the primary clustered GEE model including cognitive process, reasoning complexity, and universal task category, reasoning complexity was the only taxonomy domain independently associated with error (Wald chi-square=12.60, df=2, p=0.0018). Compared with low-complexity questions, moderate-complexity questions had 5.46-fold higher odds of failure (95% CI 2.12-14.08; p<0.001), and high-complexity questions had 7.59-fold higher odds of failure (95% CI 1.77-32.55; p=0.006). By contrast, cognitive process (Wald chi-square=6.19, df=4, p=0.185) and universal task category (Wald chi-square=0.61, df=3, p=0.893) were not independently associated with failure. Model fit for the primary specification was acceptable (QIC 1943.66; QICu 1943.65).

Sensitivity analyses using alternative working-correlation structures did not change the main inference under the independence structure, which yielded identical coefficient estimates and joint tests to the exchangeable model. Under the unstructured working-correlation specification, model fit worsened substantially (QIC 1996.70; QICu 1999.58), but reasoning complexity remained significant at the domain level (Wald chi-square=9.32, df=2, p=0.009). In that unstructured model, the moderate-complexity contrast remained significant (aOR 3.24, 95% CI 1.51-6.98; p=0.003), whereas the high-complexity contrast was attenuated and no longer individually significant (aOR 2.53, 95% CI 0.82-7.75; p=0.105).

In the supportive simplified clustered GEE model including only cognitive process and reasoning complexity, the association with reasoning complexity remained robust (Wald chi-square=13.17, df=2, p=0.001). Moderate-complexity questions had 5.14-fold higher odds of failure (95% CI 2.11-12.54; p<0.001), and high-complexity questions had 6.54-fold higher odds of failure (95% CI 1.57-27.25; p=0.010), both relative to low-complexity questions. In this simplified model, cognitive process showed a borderline overall association (Wald chi-square=8.74, df=4, p=0.068), and the `Apply` category was associated with lower odds of failure than `Remember` (aOR 0.20, 95% CI 0.06-0.69; raw p=0.011). In this updated 20-model analysis, that subgroup signal remained significant after Holm correction for the four cognitive-process contrasts (adjusted p=0.044). By contrast, the corresponding `Apply` contrast in the primary model was not significant after multiplicity adjustment (raw p=0.030; Holm-adjusted p=0.122). The simplified model showed very similar QIC to the primary model (1943.74 vs 1943.66), although QICu was slightly higher (1944.98 vs 1943.65), supporting the conclusion that the main signal was still captured by reasoning complexity rather than by broad task labeling.

The expanded full taxonomy GEE model did not improve fit and produced unstable estimates. Its QIC and QICu values (1946.44 and 1953.56, respectively, using the Remember-reference parameterization) were worse than those of the primary and simplified models. In that exploratory model, reasoning complexity remained significant at the domain level (Wald chi-square=10.47, df=2, p=0.005), whereas clinical risk (Wald chi-square=0.56, df=3, p=0.905), difficulty (Wald chi-square=0.39, df=2, p=0.821), and universal task category (Wald chi-square=0.43, df=3, p=0.934) were not. Reference recoding of the cognitive process variable left the quasi-likelihood and QICu unchanged, but QIC changed slightly through the trace-penalty component in this unstable expanded model. The recoded fit was therefore retained only as a diagnostic rather than as a separate candidate model. In supplementary exploratory analyses, models that removed knowledge dimension, difficulty, and clinical risk yielded the lowest QIC values overall, but these reduced combinations were used primarily to evaluate specification stability rather than to define the main clinical interpretation.

Taken together, these analyses indicate that LLM errors were driven predominantly by the reasoning burden required by the question. The effect was consistent across reduced clustered models and remained evident on both odds-ratio and absolute-probability scales.

**Discussion**

These findings suggest that, within this neonatal examination dataset, reasoning burden was more informative than broad topic labels for characterizing where LLMs fail. The pattern supports the view that neonatal items become challenging for current models primarily when they require sequential synthesis rather than direct retrieval.

This distinction matters because neonatal decision-making often depends on integrating physiology, diagnosis, risk assessment, and management under time pressure. At the same time, the present results come from examination questions rather than bedside care. They therefore should be interpreted as evidence about reasoning vulnerability under test conditions, not as a direct estimate of clinical deployment safety.

The role of cognitive process was more nuanced. In the primary model, the overall cognitive process domain was not independently associated with failure, although in the simplified model the `Apply` category appeared to be associated with lower odds of error than `Remember`. Because this pattern was not robust across specifications and the joint domain-level test remained non-significant, we do not interpret cognitive process as a primary independent driver of error. Instead, these findings suggest that cognitive process may partly overlap with reasoning complexity and may influence performance in a model-dependent manner.

The non-significant clinical-risk domain in the exploratory full-taxonomy model also warrants careful interpretation. A null association for the risk label does not imply that errors on clinically consequential neonatal questions are unimportant or that high-risk use cases are inherently safe. Rather, it suggests that this coarse item-level risk categorization did not explain additional variance once other overlapping taxonomy features were included, and that the present sample may have been underpowered to resolve finer safety gradients. From a safety perspective, even infrequent failures in high-acuity neonatal contexts may remain unacceptable, so future work should evaluate prospectively defined high-risk scenarios rather than infer safety from exam-derived risk tags alone.

Our model-selection results also have methodological implications. Expanded taxonomy models that simultaneously included knowledge dimension, cognitive process, reasoning complexity, clinical risk, difficulty, and task category produced poorer fit and unstable coefficients, consistent with overlap among predictors and sparse-data effects. This finding supports the use of parsimonious, clinically interpretable models for primary inference when question-level clustering is present. In particular, the reference-coding diagnostic showed that quasi-likelihood and QICu were invariant to coefficient parameterization, whereas QIC was sensitive to the trace-penalty calculation in the unstable expanded model.

These results should be interpreted in light of several limitations. First, the dataset contained a finite number of questions, and some taxonomy categories were relatively sparse, limiting precision for category-specific estimates. Second, taxonomy labels are inherently correlated constructs rather than strictly independent clinical dimensions. Third, the analysis focuses on failure against a single answer key and therefore does not directly address partial reasoning quality, uncertainty calibration, or explanation quality. Finally, although clustered GEE provides robust population-averaged inference, it does not fully characterize question-specific latent difficulty in the way that mixed-effects frameworks can.

Despite these limitations, the central message was stable: reasoning complexity was the dominant and most reproducible source of error across LLMs in this benchmark setting. For neonatal evaluation frameworks, this implies that benchmarking should emphasize reasoning burden, not only content coverage. Future studies should test this observation in larger neonatal datasets, examine interaction terms between model identity and reasoning complexity, and incorporate prospective evaluation of clinically consequential high-complexity scenarios.
